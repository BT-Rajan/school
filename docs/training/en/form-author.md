# Form Author

Read [For everyone](common.md) first. You turn the ministry's reports into forms. You see the
report catalog and forms only: never schools, people, evaluations or scanned reports.

1. **Forms** lists the ministry reports and their versions. Create a report (its ministry ID and
   whether it is about a school or a teacher), then a version with its ministry version ID and
   title in both languages. Attach the ministry's document if you have it.
2. Open the version to build the form: sections (answered by the supervisor or by a teacher),
   and questions of each type: short and long text, number, choice, yes/no, date, rating, table,
   file. A question can be shown only when an earlier answer matches.
3. Every label needs English and Arabic text. **Preview** shows the form as a phone or a computer
   will, in either language; fill it in to try it.
4. **Save** often. When it is ready, **Send for review**. A District Admin publishes it or returns
   it with comments; returned forms come back as drafts for you to change.
5. You can also draft the form's **Scoring** rules and check them against the district's worked
   examples. Only an admin activates them.
