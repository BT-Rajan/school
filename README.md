# School Cluster Evaluation System

A district system to organize schools into clusters, assign supervisors to
visit them, collect evaluations through fixed forms, and hold scanned visit
reports that each supervisor shares privately with their Cluster Head.

- [Requirements v0.3](docs/requirements.md): the current specification,
